# Manual QA Portfolio Project

A manual software testing portfolio project demonstrating the full QA process — test planning, test case design, test execution, and bug reporting — applied to a real web application.

## System Under Test

[Sauce Demo](https://www.saucedemo.com) — a demo e-commerce site built for QA practice, covering login, product browsing, cart, and checkout flows.

## What's in this repo

This README gives a quick overview. The full documentation lives in the [Wiki](../../wiki):

- **Test Plan** — scope, objectives, approach, and test environment
- **Test Cases** — structured test suite covering login, browsing, cart, and checkout
- **Bug Reports** — reproducible bugs found during test execution
- **Test Summary Report** — final results: pass/fail counts and overall assessment

## Tools

- Manual testing (no automation)
- GitHub Issues for tracking testing tasks
- GitHub Wiki for documentation
